# QSS Public Data Package

This package contains the seven project bibliographies used in the study. The
files are identified only by the case codes used in the manuscript. Source
manuscript titles and identifying project information are not disclosed because
the source manuscripts remain in progress.

| File | Case description | Scope |
|---|---|---|
| `bibliographies/C1.bib` | Visual analytics and precipitation evidence | ทัศนวิเคราะห์ เลนส์ความรู้ และหลักฐานด้านฝน |
| `bibliographies/C2.bib` | Rainfall observation and nowcasting | การสังเกตฝน และการพยากรณ์ระยะสั้น |
| `bibliographies/C3.bib` | Organelle and small-genome assembly | การประกอบจีโนมขนาดเล็ก |
| `bibliographies/C4.bib` | Thai legal question answering | การตอบคำถามกฎหมายไทย |
| `bibliographies/C5.bib` | Vehicle make and model recognition | การจำแนกยี่ห้อ และรุ่นยานพาหนะ |
| `bibliographies/C6.bib` | Computational thinking and STEM attitudes | การคิดเชิงคำนวณ และเจตคติต่อสะเต็ม |
| `bibliographies/C7.bib` | Explainable research matching | การจับคู่งานวิจัยที่อธิบายได้ |

These descriptions reproduce the wording used in the manuscript's corpus table.
All `abstract` fields are removed from the public BibTeX files. Titles retained
inside those files belong to the cited scholarly works, not to the confidential
source manuscripts.
